# Подключение Telegram к форме сайта «МойДекларант»

В этом комплекте:
- `script.js` — полный обновлённый файл сайта на основе присланного проекта; токен в браузере отсутствует.
- `worker/src/index.js` — серверный обработчик отправки заявок через Telegram Bot API.
- `worker/wrangler.jsonc` — конфигурация Cloudflare Worker с ограничением частоты запросов.

## Важное про токен

Токен нельзя записывать в `script.js` или другие публичные файлы. Добавь его непосредственно в Cloudflare как secret с именем `TELEGRAM_BOT_TOKEN`. Поскольку токен был отправлен в чат, безопаснее отозвать его через BotFather и создать новый. Если ты всё же решишь оставить текущий, в коде он всё равно должен храниться только в настройках Worker.

## Публикация через Cloudflare

Рекомендуемый способ публикации с включённым rate limiting — через Wrangler CLI версии 4.36 или новее.

1. Установи Node.js, затем из папки `worker` выполни `npx wrangler login`.
2. Если namespace ID `863294817` уже используется в этом аккаунте Cloudflare, замени `namespace_id` в `wrangler.jsonc` на другой положительный уникальный integer в формате строки.
3. Выполни `npx wrangler deploy`.
4. В Cloudflare Dashboard открой Worker `moydeklarant-telegram-relay` → Settings → Variables and Secrets → Add → Secret. Создай `TELEGRAM_BOT_TOKEN` и укажи токен приватно в интерфейсе Cloudflare.
5. Добавь `TELEGRAM_CHAT_ID`. В присланном старом `script.js` был указан ID `1126151371`. Используй его только если проверено, что это личный чат нужного владельца. Владелец должен открыть нового бота и нажать Start.
6. Нажми Deploy после добавления секретов. Скопируй URL опубликованного Worker, обычно формата `https://moydeklarant-telegram-relay.<subdomain>.workers.dev`.
7. Открой корневой файл сайта `script.js` и найди `TELEGRAM_PROXY_URL`. Замени адрес-заглушку `https://YOUR-WORKER-NAME.YOUR-SUBDOMAIN.workers.dev` на фактический URL Worker. В конце можно оставить `/` или убрать его.
8. Загрузи обновлённый `script.js` в репозиторий сайта и дождись публикации сайта.

## Если публикуешь через Dashboard вместо Wrangler

Можно создать Worker в Dashboard и вставить содержимое `worker/src/index.js` в редактор. Добавь два Secret, как описано выше. В этом случае rate-limit binding из `wrangler.jsonc` не будет подключён автоматически: для ограничения частоты запросов опубликуй Worker через Wrangler или отдельно настрой соответствующий binding. Не считай CORS самостоятельной защитой от ботов.

## Проверка

1. Убедись, что владелец нажал Start в чате нового бота.
2. Отправь тестовую заявку через реальную форму сайта.
3. Убедись, что сообщение пришло в нужный Telegram-чат и содержит имя, телефон, необязательные поля и время Asia/Tashkent.
4. Убедись, что WhatsApp открывается с подготовленным сообщением.
5. Для проверки ошибки временно останови Worker или укажи тестовый недействительный URL: форма не должна утверждать, что Telegram получил заявку; поля должны остаться доступными для повторной попытки.
6. Не отправляй тестовые заявки с реальными клиентскими данными без необходимости.

## Примечания

- Разрешённые Origin в Worker: `https://moydeklarant.uz` и `https://www.moydeklarant.uz`. Если сайт публикуется с другого домена или временного preview URL, добавь его только на время тестирования.
- CORS ограничивает браузерные запросы, но злоумышленник может напрямую обращаться к публичному Worker. Rate limiting — дополнительное ограничение, а не абсолютная защита.
- Код сохраняет прежние HTML ID формы и не требует изменений дизайна или `particle-swarm.js`.
